# hunt.k1kfx.com

K1KFX fox hunting site, served by GitHub Pages (deploy from branch `main`, root) at https://hunt.k1kfx.com.

| Path | What it is |
| --- | --- |
| `index.html`, `img/` | The Fox Hunting page (uses the shared kit from `k1kfx.com/kit/`) |
| `foxpursuit/` | The Fox Pursuit app by Andrew Lindsay, WA0MCS, unchanged apart from its four `0-config-*.js` files |

Fox Pursuit is licensed software (see `foxpursuit/LICENSE.txt`): one installation, on one domain, with the
attribution kept in the footer of every public page. Do not copy it anywhere else.

Moving or renaming the site: add the new address under Firebase (project `k1kfx-foxhunt`) → Authentication →
Settings → Authorized domains, or sign-in stops working there.
